summary
------------
- 영화관 아르바이트를 소재로한 타이쿤 게임.

- 외부 라이브러리 사용: stb (이미지 로드)

#게임모드

##스토리모드(기본모드)
-미연시가 포함되어있음
-첫출근부터 시작
-시작전에 간단하게 면접보는 식으로 이름을 물어보면 좋을듯
-출근하면 남자 매니저가 안내함
-이후 여자 선임 알바생이 교육
-게임을 진행하며 여자 인물들과의 서사 진행
-몇일 할지는 추후

###모드 진행방식
- 매점, 검표, 플로어 중 랜덤 1
- 첫날은 무조건 플로어
- 중간 쯤 부턴 검표 플로어 합쳐서 하기도 함 -> 남자 동료 찐빠
- 비성수기 였다가 대작으로 인해 성수기도 됐다가 하는 내용의 스토리 있음 좋을듯

####플로어
- 영화관 청소 담당
- f키로 청소등 키기
- wasd를 이동하며 청소
- 팝콘이 쏟아지면 스페이스 연타
- 음료가 쏟아지면 쉬프트 연타
- 퇴장 시간과 다음 입장 시간을 확인하고 그 시간 전까지 완료해야함
- 제한시간 존재 (다음 영화 입장시간)
- 엔딩 크레딧을 재밌게 만들면 좋을듯

####검표
- 타겜 모티브로 하면좋을듯
- 날짜, 시간, 영화 제목, 관
- 날짜와 시간을 잘 봐야함
- 영화 시작 시간 전에 다 들여보내야 함
- 밑에 인원 수 적어주면 좋을듯
- 손님이 알맞는 관에 안가고 다른 관에 가는 것도 잡아야함 (난이도가 높아지면)
- 관타기도 함 (역시 난이도가 높아지면)

####매점
- 오버쿡드 매커니즘 어떤지
- 메뉴 : 팝콘, 음료, 핫도그, 나쵸, 굿즈 정도?
- 팝콘 -> 튀기기 / 푸기 두개 하면 될듯, 튀기는건 기름 버튼 -> 옥수수 넣기 -> 시즈닝 넣기
- 오버쿡드 처럼 제한시간 안에 팝퍼기 안내리면 타서 패널티
- 핫도그는 빵 넣기 -> 소세지 넣기 -> 전자레인지
- 음료는 알맞은 디스펜서에 사이즈로
- 나쵸, 굿즈는 그냥 올려놓기 정도
- 키오스크로 주문해서 딱히 결제할 일은 없을 듯

###미연시
- 3인의 히로인 (선임, 동기, 매니저)
- 일 이외의 별도 스토리
- 골고루 경험하기 vs 한명에게 집중하기
- 한명에 집중할 수 있게 선택지를 주는게 좋을 거 같긴 하지만 너무 몰빵되지 않게 하면 좋긴 할듯
- 메인 히로인은 선임으로 -> 처음 교육 시켜주기도 하고, 가장 많이 겹칠 듯
- 밖에서 데이트를 하면 평상복 입고 등장
- 회식도 존재, 여기서 어떻게 하느냐에 따라 호감도 천차만별
- 영화관 사람들끼리 놀러가는 이벤트 (바다 등), -> dlc로 해도 될듯? 수영복 같은거
- 1명 호감도 -50일시 해고당하는 배드엔딩 존재
- 멀티 엔딩으로 ㄱㄱ, 배드엔딩도 여러개 있음, 매니저랑 점장 엔딩도 존재

##도전모드 (찐 알바생모드)
- 프레디의 피자가게 처럼 1일차, 2일차 이런식으로 진행됨
- 역시나 랜덤
- 3일차까지 무난하지만 4일차부터 어려워짐
- 4일차부터 검표+플로어
- 7일차 완료 시 매니저되는 엔딩

###NPC
- 선임 알바 = 첫번째 히로인
- 동기 알바 = 두번째 히로인
- 매니저 = 세번째 히로인
- 남자 매니저
- 점장
- 남자 동료

#세계관
- 어느 한 작은 마을의 작은 영화관의 이야기
- 마을에는 영화관이 이 영화관 밖에 없음
- 마을 사람들이 전부 영화를 좋아해서 다양한 국적과 장르의 영화들을 개봉
