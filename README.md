CINEMA HOLIC!
============
summary
------------
- 영화관 아르바이트를 소재로한 타이쿤 게임.
- 미니게임을 진행하고, 영화관과 함께 성장하세요!
- 동료들과 즐거운 추억을 쌓고 행복한 엔딩을 맞이하세요!

development
------------
- 개발 언어: C/C++
- 윈도우 시스템: WinAPI
- 그래픽스 API: DirectX 11
- 플랫폼: Windows
- 외부 라이브러리 사용: stb (이미지 로드)

기획의도
------------
누구나 한번 쯤은 해보고 싶었던 '영화관 아르바이트'

힘들게 일하지 말고 게임으로 하면 됩니다.

현실적이면서도 로망 가득한 영화관 아르바이트 시뮬레이터.

ps.기본적으로 패러디가 많이 들어갔으면 좋겠음. 영화 패러디.
저작권에 문제 없는지는 잘 알아봐야할 듯.
게임이 복잡하지 않고 외워야하는 키가 너무 많지 않았으면!

게임모드
------------
### 1. 첫시작
- 면접을 보는 식으로 시작
- 이름을 물어봐서 플레이 중 불릴 이름을 정하기
- 영화관 알바 경험이 있는지 묻기 (이건 그냥 순수 질문)
- 영화관 알바에 지원한 이유가 무엇인지 (돈vs친목) -> 돈을 고르면 일을 미친듯이 하여 돈을 많이 벌지만 연애나 친목은 하지 못한 약간의 배드엔딩? 나오게 하면 좋을 듯. 친목은 그냥 스토리모드
- 어쩌면 이 질문은 스토리를 진행하고 동료나 선임이 물어보는 게 더 자연스럽고 엔딩나오기도 괜춘할지도.. 의견부탁
- 꽤나 바쁠텐데 자신이 있는지 묻기 (네!, 바쁘다고요..?, 저는 그런 것 따윈 신경쓰지 않습니다. 등의 선택지 주기)
- 쨌든 자연스럽게 스토리 모드로 시작

### 2. 스토리모드(기본모드)
-미연시가 포함되어있음
-첫출근부터 시작
-출근하면 남자 매니저가 안내함
-이후 여자 선임 알바생이 교육
-게임을 진행하며 여자 인물들과의 서사 진행
-몇일 할지는 추후
-미연시인 만큼 선택지를 중요하게 만들어야 할듯 (ex. 호감도나 엔딩에 영향을 주는)
-휴무신청일에 대한 선택지를 줘서 누구를 만날지 정하는 것도 재밌을 듯 (ex. 1 9월 18일 (동료) 2 9월 19일 (선임) 3 9월 20일 (매니저))

### 3. 모드 진행방식
- 매점, 검표, 플로어 중 랜덤 1
- 첫날은 무조건 플로어
- 중간 쯤 부턴 검표 플로어 합쳐서 하기도 함 -> 남자 동료 찐빠
- 비성수기 였다가 대작으로 인해 성수기도 됐다가 하는 내용의 스토리 있음 좋을듯

### 4. 플로어
- 영화관 청소 담당
- 크레딧과 쿠키 영상을 적절히 넣어 후반에는 제한 시간이 흘러감에도 잘 나가지 않는 관객에 의해 난이도를 올려주는 것도 나쁘지 않을 듯
- f키로 청소등 키기, 끄기 시작과 끝에만 키면 됨. (청소 시작 전에 키지 않으면 시간 -20초 이런 패널티 주는 식으로)
- wasd를 이동하며 청소
- 팝콘이 쏟아지면 스페이스 연타
- 음료가 쏟아지면 쉬프트 연타
- 퇴장 시간과 다음 입장 시간을 확인하고 그 시간 전까지 완료해야함 (그냥 제한시간만 있어도 될 듯? 이건 추후 논의)
- 제한시간 존재 (다음 영화 입장시간)
- 엔딩 크레딧을 재밌게 만들면 좋을듯

### 5.검표
- 타겜 모티브로 하면좋을듯
- 날짜, 시간, 영화 제목, 관
- 날짜와 시간을 잘 봐야함
- 영화 시작 시간 전에 다 들여보내야 함
- 밑에 인원 수 적어주면 좋을듯
- 손님이 알맞는 관에 안가고 다른 관에 가는 것도 잡아야함 (난이도가 높아지면)
- 관타기도 함 (역시 난이도가 높아지면)

### 6. 매점
- 오버쿡드 매커니즘 어떤지
- 메뉴 : 팝콘, 음료, 핫도그, 나쵸, 굿즈 정도?
- 팝콘 -> 튀기기 / 푸기 두개 하면 될듯, 튀기는건 기름 버튼 -> 옥수수 넣기 -> 시즈닝 넣기
- 오버쿡드 처럼 제한시간 안에 팝퍼기 안내리면 타서 패널티
- 핫도그는 빵 넣기 -> 소세지 넣기 -> 전자레인지
- 음료는 알맞은 디스펜서에 사이즈로
- 나쵸, 굿즈는 그냥 올려놓기 정도
- 키오스크로 주문해서 딱히 결제할 일은 없을 듯

### 7. 미연시
- 3인의 히로인 (선임, 동기, 매니저)
- 일 이외의 별도 스토리
- 골고루 경험하기 vs 한명에게 집중하기
- 한명에 집중할 수 있게 선택지를 주는게 좋을 거 같긴 하지만 너무 몰빵되지 않게 하면 좋긴 할듯
- 메인 히로인은 선임으로 -> 처음 교육 시켜주기도 하고, 가장 많이 겹칠 듯
- 밖에서 데이트를 하면 평상복 입고 등장
- 회식도 존재, 여기서 어떻게 하느냐에 따라 호감도 천차만별
- 영화관 사람들끼리 놀러가는 이벤트 (바다 등), -> dlc로 해도 될듯? 수영복 같은거
- 1명 호감도 -50일시 해고당하는 배드엔딩 존재
- 멀티 엔딩으로 ㄱㄱ, 배드엔딩도 여러개 있음, 매니저랑 점장 엔딩도 존재

### 7. 도전모드 (찐 알바생모드)
- 프레디의 피자가게 처럼 1일차, 2일차 이런식으로 진행됨
- 역시나 랜덤
- 3일차까지 무난하지만 4일차부터 어려워짐
- 4일차부터 검표+플로어
- 7일차 완료 시 매니저되는 엔딩

NPC
------------
- 선임 알바 = 첫번째 히로인
- 동기 알바 = 두번째 히로인
- 매니저 = 세번째 히로인
- 남자 매니저
- 점장
- 남자 동료

세계관
------------
- 어느 한 작은 마을의 작은 영화관의 이야기
- 마을에는 영화관이 이 영화관 밖에 없음
- 마을 사람들이 전부 영화를 좋아해서 다양한 국적과 장르의 영화들을 개봉
